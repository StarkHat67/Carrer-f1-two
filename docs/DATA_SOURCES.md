# Fontes do catálogo 2026

Última revisão: 20/09/2026.

Este projeto usa nomes e vínculos piloto/equipe como dados factuais de referência para criar o estado inicial do save. Não usa fotos, logos, uniformes ou artes oficiais.

## Importante

- `starting_overall`, `potential` e atributos de pilotagem são valores de balanceamento criados para o jogo. Não são avaliações oficiais das categorias, equipes ou pilotos.
- As cores usadas na interface são apenas marcadores visuais do jogo; não há logos oficiais.
- Números, escalações e demais dados factuais devem ser revisados antes de uma atualização pública do catálogo.
- O save é uma linha do tempo fictícia a partir do início da carreira. Resultados reais posteriores não sobrescrevem o universo do jogador.
